# @offense-demo/db

Owner: Platform/data (see CODEOWNERS scaffold).

The platform persistence layer: typed operations for auth (Better Auth's adapter, session revocation, email change), username onboarding, email delivery, the realtime outbox (append, drain, LISTEN), retention and owner-scoped projects (`insertProject`, `listProjectsForOwner`, plain records only: no `@offense-demo/domain` dependency), plus migrations and bounded PostgreSQL connections. Public API: `createDatabase`, `Database`, `UsernameClaim`, `DatabaseEventSink`, the outbox cursor helpers and `refuseSchemaAlteringRole`. Product tables and their operations are added beside these, one area module per domain, composed into `createDatabase`. Depends on Drizzle 1.0 (ADR 0038), Bun, `@offense-demo/protocol` (vocabularies, topic builders and every jsonb column's schema; ADR 0029) and `@offense-demo/errors` (the typed `VALIDATION` error a mis-shaped jsonb write fails with). The `./slots` export is local slot tooling (databases, resets, `provisionTestRoles`), and the `./dev-seed` export (`applyDevSeed`) is the one write path of `bun db:seed`; neither is imported on the request path. Application code passes portable values; tables and drivers are private. See docs/architecture/persistence.md and docs/operations/database.md.

Run `bun run typecheck` and `bun test src` from this package. Integration-enabled packages expose `bun run test:integration`; tests require explicit test infrastructure variables. All imports use the public package export.
